# Projeto DNA Financeiro

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Shadcn UI
- Supabase
- Recharts
- Lucide React

## Regras de trabalho
- Trabalhar sempre por etapas.
- Não ler o projeto inteiro sem necessidade.
- Antes de alterar código, listar quais arquivos serão analisados.
- Fazer alterações pequenas e incrementais.
- Não reescrever arquivos inteiros se puder aplicar patch.
- Não criar dependências sem necessidade.
- Não alterar banco de dados sem autorização.
- No final, informar apenas:
  1. arquivos alterados
  2. o que mudou
  3. como testar
  4. próximo passo

## UI/UX
- Mobile first.
- Visual moderno, limpo e premium.
- Usar cards arredondados.
- Usar botões grandes e claros.
- Usar linguagem humana, simples e motivadora.
- Evitar telas longas e cansativas.
- Perguntas devem ser progressivas.
- Sempre entregar valor antes de pedir muitos dados.

## Cores sugeridas
- Azul escuro para confiança.
- Verde para evolução financeira.
- Dourado/amarelo para oportunidades.
- Vermelho suave para alertas.
- Cinza claro e branco para limpeza visual.

## Produto
O DNA Financeiro é um app gratuito que ajuda o usuário a:
- entender sua realidade financeira;
- controlar gastos;
- cadastrar sonhos;
- receber perguntas inteligentes;
- acessar oportunidades;
- cadastrar habilidades para renda extra;
- receber recompensas;
- futuramente integrar com app de diárias.
